Ruby, Homebrew, etc. on macOS

Ruby

是一门编程语言

Ruby is…

A dynamic, open source programming language with a focus on simplicity and productivity. It has an elegant syntax that is natural to read and easy to write. Ruby official website

Homebrew

包管理工具

Formulae

A formula is a package definition written in Ruby. Formula Cookbook

Casks

Homebrew Cask extends Homebrew and brings its elegance, simplicity, and speed to the installation and management of GUI macOS applications such as Visual Studio Code and Google Chrome. Homebrew Cask GitHub repo

🤔️ 个人理解

Formulae 是核心功能，多是命令行形式使用

Casks 是预编译可执行文件，多是带 GUI 的工具软件

🧾 总结

  1. Homebrew 是 macOS 上的 包管理工具

  2. Homebrew 安装的包可以分为 Formulae 和 Casks
    其中 Formulae 属于 核心类功能；Casks 属于 GUI型工具，更注重用户交互

  3. Homebrew 依赖 Ruby，从自身安装，到Formulae/Casks 定义

  5. Ruby Gem 是 Ruby 的 包管理工具；CocoaPods 是使用 Ruby 编写的 iOS/macOS 第三方库管理工具
